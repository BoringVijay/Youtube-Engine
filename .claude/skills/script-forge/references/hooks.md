# Hooks

The first sentence states the promise. The first frame shows it. Both agree. Under 2.5 seconds, about 8 words.

## Patterns that work for us
| Pattern | Shape | Example |
| --- | --- | --- |
| Absurd number | Number + time/scale contrast | "Six billion dollars. Twenty minutes." |
| What-if cold open | Scenario + instant consequence | "If the Moon vanished tonight, you'd notice in 5 minutes." |
| Wrong belief | Common belief, then flip | "You think your money's in the bank. It isn't." |
| Mid-action | Start inside the story | "At 3:12 a.m., the alarms at Binance went silent." |
| Stakes for you | Personal consequence | "This one rule is why your phone dies at 20%." |
| The confession | Narrator admits something | "I explained this wrong for years." |
| Comparison | Two things that shouldn't match | "A pizza and a nuclear reactor have one thing in common." |

## Rules
- No greeting, no logo, no channel name in the first 3 seconds.
- Text on screen says the hook in ≤ 5 words, heavy type.
- A visual change happens in the first second (pattern interrupt).
- Never promise what the script doesn't deliver. A broken promise tanks the rest of the curve.
- Write 5, pick 1, keep the other 4 in the job file for A/B tests later.

## Banned
Questions with obvious yes/no answers. "Did you know...". "Wait for the end". Fake urgency. Clickbait we can't back up.
