# Structures

## Short (35-55 s, 95-150 words)
| Time | Beat | Job |
| --- | --- | --- |
| 0-3 s | Hook | Promise + visual proof |
| 3-10 s | Setup | The one thing you need to know, as an image |
| 10-35 s | Escalation | 2-3 steps, each bigger or weirder. Visual change every 1-2 s |
| 35-45 s | Twist / payoff | The surprise lands. Our take in one line |
| last 3 s | Loop or button | A line that makes the start make sense again, or a dry joke |

## Long explainer (4-7 min, 650-1,150 words)
| % of runtime | Beat | Job |
| --- | --- | --- |
| 0-8% | Cold open | Hook, stakes, and a promise of what they'll understand by the end. Open loop #1 |
| 8-20% | Ground floor | The simplest mental model, with one analogy |
| 20-45% | Mechanism | How it actually works, step by step as a story. REHOOK. Open loop #2 |
| 45-70% | Complication | The twist, the failure, the part nobody expected. Close loop #1 |
| 70-88% | So what | What it means for the viewer. Our TAKE. Close loop #2 |
| 88-100% | Payoff + button | Callback joke, one-line summary, in-character CTA |

## Format variants
- **What-if**: escalate on a timeline ("in 5 minutes... in a week... in a million years").
- **What happened**: mid-action open, then rewind ("To get how, we need to go back 3 days").
- **How it works**: start with the everyday thing, then zoom in layer by layer.
- **Versus**: two contenders, a scorecard that updates on screen, a verdict.

## Transitions that pull forward
"But here's the catch." · "Which sounds fine. Until..." · "And that's where it gets weird." · "Now hold that thought." · "Remember the [callback]? Yeah." · "So who's actually to blame? [beat] Kind of everyone."
