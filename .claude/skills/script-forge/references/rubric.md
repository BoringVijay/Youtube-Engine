# Rubric (score each 1-5, ship at ≥ 40/50, nothing below 3)

| Category | 5 looks like | 1 looks like |
| --- | --- | --- |
| Hook | Promise in ≤ 8 words, visual matches, I'd stop scrolling | Greeting, topic statement, vague question |
| Clarity | A 14-year-old could re-explain it | Jargon left untranslated |
| Story | Tension, escalation, a turn | A list of facts |
| Personality | Sounds like the narrator, one real laugh, one clear take | Could be any AI channel |
| Accuracy | Every claim sourced, science mechanism right | Unsourced numbers, hand-waving |
| Visuals | A change every 1-2 s (Short) / 4-6 s (long), each cue drawable | "Show image of X" for every beat |
| Pacing | No sentence restates the last one; WPM in range | Padding, repeated ideas |
| Payoff | Ending pays the hook's promise, callback lands | Fizzles, or new info dumped at the end |
| Packaging | 3 titles + thumbnail text that match the hook | Titles unrelated to the open |
| Originality | Angle we haven't seen in the top 10 results | Rewording a popular video |

Write the scores and one-line reasons into `script.json`. If a category scores below 3, fix that first.
